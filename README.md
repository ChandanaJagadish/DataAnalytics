## Projects

### 🏈 [Premier League ETL Pipeline](./Football_League_ETL_pipeline)
An end-to-end ETL pipeline that pulls live Premier League match data from a
public API, loads it into PostgreSQL, and analyzes what factors (home
advantage, recent form, goal difference) correlate with match outcomes.

**Tech:** Python, pandas, PostgreSQL, psycopg2, matplotlib, REST API
